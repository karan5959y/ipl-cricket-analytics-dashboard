# IPL Cricket Analytics Dashboard | Power BI

## Project Overview

An interactive 3-page Power BI dashboard created to analyze IPL match,
ball-by-ball delivery, team, and player performance data.

## Tools & Technologies

- Power BI
- DAX
- Data Cleaning
- Data Visualization

## Key KPIs

- Total Matches
- Total Runs
- Strike Rate
- 4s and 6s
- Team Win Counts

## Dashboard Features

- Season-wise analysis
- Team-wise performance
- Venue-wise analysis
- Player performance analysis
- Interactive slicers and filters
